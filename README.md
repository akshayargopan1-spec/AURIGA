# PeerSolve 🎓🤝

### Learn What You Need. Teach What You Know.

PeerSolve is an **AI-powered reciprocal peer-learning platform** designed to help students identify their learning gaps, find the right peers, learn together, and measure their improvement.

## 🚨 Problem

Students often know their marks but not their specific skill gaps. They may also struggle to find the right person to help them with a particular topic. Existing academic platforms mainly focus on attendance, marks, courses, and records rather than creating a continuous peer-learning cycle.

## 💡 Solution

PeerSolve creates a continuous learning loop:

**Assess → Identify → Plan → Match → Learn → Measure → Improve**

Students first complete a baseline assessment. AI identifies their learning needs and creates a personalized study plan. PeerSolve then finds a compatible student based on complementary skills, learning goals, availability, and skill level.

### Example

**Student A**

* Knows Python
* Needs React

**Student B**

* Knows React
* Needs Python

PeerSolve connects them for a **reciprocal knowledge-exchange session**.

## 🔐 Security & Privacy

* Student identity verification
* Skill verification
* Role-based access
* Firebase security rules
* Privacy controls
* Assessment integrity monitoring
* Peer feedback and reporting
* Minimal data sharing for peer matching

## 🏆 Key Innovation

Unlike systems that only predict performance or provide learning content, PeerSolve creates a **closed learning feedback loop**:

> **Assess → Find the Gap → Find the Right Peer → Learn → Measure Improvement → Update Skills**

It also rewards **improvement, consistency, peer contribution, and learning progress**, rather than ranking students only by marks.
